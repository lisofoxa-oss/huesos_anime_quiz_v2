# 🔥 АНИМЕ-КВИЗ ДЛЯ ЁБАНЫХ ДЕГЕНЕРАТОВ

> Угадай тайтл по описанию — если сможешь. Спойлер: не сможешь.

**[▶️ ИГРАТЬ ПРЯМО СЕЙЧАС](https://lisofoxa-oss.github.io/huesos_anime_quiz_v2/)**

---

Здесь нет мягких формулировок и вежливых подсказок. Есть 100+ тайтлов, пересказанных максимально грубо, честно и без цензуры — а твоя задача узнать их по одному предложению, пока не кончились жизни и не истёк таймер.

Думаешь, ты шаришь в аниме? Легко попадёшь на "лёгком" уровне и с треском проебёшься на "сложном". Проверено.

## 🎮 Что тебя ждёт

- **10 вопросов** за раунд, **3 жизни**, **20 секунд** на каждый ответ — тик-так, тик-так
- Квиз **обращается к тебе** — выбери, как с тобой разговаривать: как с братаном или как с крошкой
- В конце — **радар твоей аниме-души**: жестокость, мозголомность, пошлость, мрачность и другие статы по тайтлам, которые ты угадал
- Каждый правильный и неправильный ответ — со своей порцией отборного разноса

## 🟢🟡🔴🦕🍆 Пять уровней ада

| Уровень | Что внутри |
|---|---|
| 🟢 **Лёгкий** | Наруто, Атака титанов, Тетрадь смерти — база, которую обязан знать каждый |
| 🟡 **Средний** | Берсерк, Монстр, Винланд Сага — тут уже не отделаешься тиктоком |
| 🔴 **Сложный** | Лэйн, Текснолайз, Эрго Прокси — нишевое говно для избранных психов |
| 🦕 **Динозавр** | Сейлор Мун, Покемоны, Гандам — если знаешь, тебе либо за 30, либо ты коллекционер кассет |
| 🍆 **Хентай** (18+) | Bible Black, Euphoria и другое — только для честных дегенератов, вход строго по возрастному чек-апу |

## 🛠 Как это работает

Всё живёт в одном `index.html` + пачке JSON-файлов с вопросами и фразами — никаких бэкендов, никакой сборки, открыл и играешь. Заходит и с телефона, и с компа.

```
index.html          — вся логика и стили
data_easy.json      — лёгкий уровень
data_medium.json    — средний уровень
data_hard.json      — сложный уровень
data_dino.json      — уровень "динозавр"
data_hentai.json    — 18+ уровень
phrases.json        — все реплики (мужской/женский вариант)
```

## 🚀 Запустить у себя

Склонировал репо → открыл `index.html` в браузере (или через любой локальный сервер, чтобы `fetch()` подтягивал JSON без CORS-истерик) → всё работает.
